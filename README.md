# Daylight for Windows — Downloads

Daylight is a local screen-time app for Windows with an AMOLED interface.

Download the Windows installer from [Releases](https://github.com/mokkshchoudhary/screen-time-win-releases/releases). Releases include separate x64 and ARM64 packages. The installer includes the .NET runtime.

Recording starts off. Enable it in the app when you are ready. Your activity history stays on your PC; it is not uploaded to GitHub. Website tracking is optional and requires the Chrome companion and per-profile consent. The app does not capture page contents, passwords, screenshots, or keystrokes.

Installed builds check this repository for updates and download them in the background. Settings shows when a new version is ready and lets you restart to install it. Your history is stored separately from application files.

This repository contains public release downloads and update metadata. Application source is maintained in a separate private repository. Early builds are unsigned until publisher signing is provisioned. Chrome companion setup instructions are included in the installation.
